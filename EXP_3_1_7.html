Chapter knowledge check multiple choice

Two waves cos(2x − 6t) and cos(4x − 12t) are superposed. Both have the same phase speed. What is that phase speed, and are the group speed and phase speed equal?

vₚ₁ = 6/2 = 3, vₚ₂ = 12/4 = 3. Both waves travel at 3 m/s — this is a non-dispersive pair. Envelope speed uₘ = Δω/Δk = (12−6)/(4−2) = 6/2 = 3 m/s. In a non-dispersive medium, group speed always equals phase speed. The carrier travels at ω̄/k̄ = 9/3 = 3 m/s. Everything moves at 3 m/s.
